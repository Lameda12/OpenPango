Rules the harness enforces

  • Immutable event logEvery tool call is a hash-chained row. Updates and deletes are rejected by the database.
  • Humans approve the risky stuffRefunds over $75.00 and lost packages only file an approval request.
  • No invented ETAsDrafts are checked against carrier data. Anything unsupported is blocked, not sent.
  • Scoped toolsThe email writer cannot refund. The returns agent cannot approve its own request.
